# hab-art — Habblaud pixel art engine (bundled)

Procedural pixel-art engine bundled from [Habblaud](https://github.com/marmottajr/habblaud) (MIT, © Márcio Junior).
Contains only the client art module (characters, furniture, floors, walls) compiled to a single browser JS file
exposing `window.HabArt` (renderCharacter, renderFurniture, floorChunk, wallFaceTile, renderRug).
Used by Panel Agen. See LICENSE-HABBLAUD.
